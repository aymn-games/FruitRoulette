Drop these image files into the folder_images/ folder. Until they exist, the
game automatically falls back to emoji so everything still works for testing.

Required for the fruit crate popup:
  apple.png
  banana.png
  grape.png
  orange.png
  pineapple.png
  strawberry.png
  kiwi.png
  hidden_character.png   <- the elimination image

Optional, used in the wheel's center hub:
  hub_icon.png

Already included:
  aymn_logo.png   <- شعار العاب أيمن، يظهر في أعلى الصفحة

Recommended size: square, at least 256x256px, transparent background (PNG).
